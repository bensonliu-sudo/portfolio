## Development

A buildless static site with no runtime dependencies, external fonts or analytics.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Open http://127.0.0.1:4173. The homepage is `index.html`; shared styles and scripts are in `assets/`; case-study pages under `work/` are generated by `python3 tools/build_case_studies.py` (edit the script, not the generated HTML). `api/contact.js` is the only server-side code: a Vercel function for the contact form, which reads its Web3Forms key from the `WEB3_FORM` environment variable.

## Deployment

Import this repository into Vercel. Framework preset: **Other**. No build command; serve the repository root. The production domain is **bingchengliu.com**, with `www` redirecting to the apex domain.

The projects are shown through screen recordings of their real interfaces running on synthetic or fictional data. This portfolio does not host any project backend, database or private development records.
