PROJECT / 01

Multi-factor
stock scoring

Researchers choose the factors, directions and weights. The tool turns those settings into exact, reproducible scores, rankings and an auditable stock pool, and explains every result factor by factor.

  • Weight sandbox. Drag a weight and the pool re-scores live, showing which stocks entered, left or moved.
  • Cutoff explanation. How far each stock is from the rank-N threshold, and which factor drives the gap.
  • Audit trail. Every run is stored with its config snapshot and data fingerprint, so any pool can be reproduced.

Approach

Built with AI.
Verified like production.

AI writes much of the code. What makes the result trustworthy is the process around it.

01

Specify, then verify the spec

Every ambiguous rule is pinned down and checked against an independent reference, cell by cell, before features are built on it.

02

Build in gated packages

Work ships in packages. Each is frozen, hashed and handed over; nothing moves forward until it passes review.

03

Independent adversarial review

A second AI re-computes results, injects faults and replays real usage. Every finding is fixed and re-tested.
